# Fullstack Todo App (React + Node + MySQL)

Une application de gestion de tâches complète avec un frontend moderne et un backend robuste.

## Technologies utilisées

| Secteur | Technologies |
| :--- | :--- |
| **Frontend** | React, Vite, Tailwind CSS, DaisyUI, Axios |
| **Backend** | Node.js, Express, Nodemon |
| **Base de données** | MySQL (WAMP/XAMPP) |
| **Outils** | Concurrently, Dotenv, CORS |
